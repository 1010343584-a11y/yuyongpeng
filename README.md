## 🔄 日常操作指南

### 添加新内容

1. 找到对应板块的文件夹
2. 在该文件夹内新建 `.md` 文件
3. 写入内容后保存
4. 对我说：「**同步到 GitHub**」→ 我会自动帮你上传

### 修改已有内容

1. 直接编辑对应文件
2. 修改完成后对我说：「**同步到 GitHub**」

### 快速查看

打开 GitHub 网页，可以看到所有文件的最新状态和修改记录。

## ⚠️ 注意事项

- **文件命名**: 使用中文或拼音，不用特殊字符
- **文件位置**: 不要改动现有文件夹名称和结构
- **敏感信息**: 不要在文件里写密码、令牌等敏感信息
- **大文件**: `.xlsx` 表格文件可以放，但单个文件不超过 10MB
