## 🎯 这个库的作用

收录平台上所有能参考的高赞笔记，拆解它们的 **标题、开头钩子、结构、标签**，为自选题提供弹药。

## 📚 笔记拆解模板（复制下方使用）

```markdown
### 【日期】博主昵称 —— 笔记标题

- **发布日期：** YYYY-MM-DD
- **平台：** 小红书 / 抖音 / 其他
- **分类：** #心灵成长 #情绪管理 / #情感关系 / #自我成长 ...
- **数据表现：**
  - 点赞：XXXX
  - 收藏：XXXX
  - 评论：XXX
- **为什么火（拆解）：**
  - 标题技巧：
  - 开头钩子：
  - 内容结构：
  - 情绪触发点：
  - 结尾互动：
- **我能借鉴什么：** （写出你的选题灵感）
```
