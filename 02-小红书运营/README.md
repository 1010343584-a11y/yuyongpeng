# 02-小红书运营

> 最后更新：2026-11-23

---

## 📂 模块结构

| 子文件夹 | 用途 |
|---|---|
| `选题Brief/` | 每日选题 Brief（自动归档） |
| `爆款素材库/` | 拆解平台高赞笔记 → 标题、钩子、结构、标签 |
| `标签词库/` | 垂类标签 + 泛流量标签清单 + 效果追踪表 |
| `竞品分析/` | 跟踪同赛道账号的成长路径和内容规律 |

---

## 📋 使用节奏

| 频率 | 操作 |
|---|---|
| **每天** | 填选题 Brief → 保存进 `选题Brief/` |
| **每周** | 找 3-5 条高赞笔记拆解，存入 `爆款素材库/`；检查标签词库有无新发现 |
| **每月** | 做一版竞品分析更新；清理废弃标签 |
