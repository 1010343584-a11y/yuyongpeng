# 03-抖音运营

> 最后更新：2026-11-23

---

## 📂 模块结构

| 子文件夹 | 用途 |
|---|---|
| `数据追踪/` | 每日视频数据录入（Excel + README 模板） |
| `主题规划/` | 月度内容主题排期 + 灵感池 |
| `灵感库/` | 随手记灵感，周末统一整理到主题规划 |
| `发布计划/` | 发布时间策略、形式矩阵、周排期表 |

---

## 📊 Excel 文件

| 文件 | 说明 |
|---|---|
| `抖音数据追踪表.xlsx` | 三表合一：每日数据 + 周复盘 + 月度汇总，含示例数据 |

---

## 📋 使用节奏

| 频率 | 操作 |
|---|---|
| **发完当天** | 把播放量、点赞等填入 Excel「每日数据」sheet |
| **每周末** | 在「周复盘」sheet 填写当周汇总，写本周最佳和最差 |
| **每月底** | 填写「月度汇总」sheet，看趋势和成长曲线 |
| **随时** | 想到灵感就丢进 `灵感库/` |
| **每月初** | 在 `主题规划/` 定当月发布排期 |
