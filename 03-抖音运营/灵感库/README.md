# 💡 灵感库

> 所属模块：03-抖音运营 / 子模块 3
> 最后更新：2026-11-23

---

## 🎯 这个库的作用

**随时记灵感的地方**——任何时候冒出来的想法、看到的触动你的一句话、想到的一句开头、网友评论里的金句，全部丢进来。周末统一整理进主题规划。

---

## 📝 灵感卡片格式

每个灵感一条，用下面这个格式：

```markdown
### 💡 灵感编号 · 简短描述

- **日期：** YYYY-MM-DD
- **来源：** 随手想到的 / 看到某条笔记 / 用户评论 / 国学原文...
- **灵感内容：** （详细描述）
- **适用形式：** 口播 / 故事 / 语录 / 图文
- **关联国学知识点：** （如果有的话）
```

## 🗂️ 灵感条目

### 💡 001. 【待定】用"厉娜体"做情感收尾主题

- **日期：** 2026-11-23
- **来源：** 今日热搜观察
- **灵感内容：** "累了就喊一声厉娜"——现代人需要一个情绪出口。可以出一期讲"为什么我们需要一个情绪的句号"，结合中庸的'慎独'概念。
- **适用形式：** 真人出镜口播
- **关联国学知识点：** 中庸·慎独
- **状态：** ✅ 可用 / ⏳ 待排 / ❌ 放弃

### 💡 002. 【待定】"...不是贪玩，是好好爱自己"

- **日期：** 2026-11-23
- **来源：** 热搜话题「累了就出去玩」
- **灵感内容：** 女生觉得"出去玩 = 偷懒"是从小被灌输的错误观念。其实出去走走就是充电。可以结合道德经"无为"的概念来聊。
- **适用形式：** 真人出镜·边走边说
- **关联国学知识点：** 道德经·无为而治
- **状态：** ⏳ 待排

### 💡 003. 【待定】王阳明那段话，说的就是你上周的那件事

- **日期：** 2026-11-23
- **来源：** 爆款笔记拆解
- **灵感内容：** "别人随口一句话，你能难受一整天"——这就是王阳明说的"你未看此花时，此花与汝心同归于寂"。你不看，它就不存在。
- **适用形式：** 真人出镜·对镜头说话
- **关联国学知识点：** 王阳明心学·心外无物
- **状态：** ⏳ 待排

### 💡 004. 【待定】..."我画地为牢啊，厉娜"——你不是过不去，是你不肯给自己句号

- **日期：** 2026-11-23
- **来源：** 综艺《后会友期》衍生梗
- **灵感内容：** 那个梗火的原因是什么？因为它提供了一种"给情绪收尾"的方式。心理学叫未完成事件。人可以不需要答案就能翻篇——你只要承认"这件事发生过，我确实难受过"。
- **适用形式：** 口播 + 文字截图
- **关联国学知识点：** 中庸·慎独
- **状态：** ⏳ 待排

## 🔄 整理规则

| 步骤 | 说明 |
|---|---|
| ① 随时记录 | 任何时间想到的就加一条，不用等整理 |
| ② 每周筛选 | 周日晚上浏览本周所有灵感，选出 3-5 条推进到主题规划 |
| ③ 每月清零 | 月底还没被选中的灵感，重新评估后决定是否保留 |
| ④ 标记状态 | ✅ 已排期 / ⏳ 待排 / ❌ 放弃 |
